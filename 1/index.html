01

From Glass Plate
to Color Image

Prokudin-Gorskii recorded each scene through blue, green, and red filters. The digitized glass plate stores those grayscale exposures vertically in B–G–R order. I split the plate into equal thirds, align the green and red images to blue by default, and stack the result as [R, G, B]. A few documented failure cases instead keep green fixed.

The reconstruction assumes that an integer translation is enough: no rotation, scale change, warping, or color correction is applied.

02

Single-Scale
Alignment

For each low-resolution JPEG, I keep blue fixed and exhaustively test every green and red translation from −15 through +15 pixels in both axes. Each candidate is created with np.roll and scored against the same interior region of the reference image.

L₂(A, B) = √(Σ(A − B)²)

NumPy subtracts and squares corresponding pixels element by element. The smallest distance wins, so a better match means a lower score.

Rolling an array wraps pixels from one edge to the opposite edge. Since the largest candidate displacement is 15 pixels, I remove a fixed 15-pixel border after each shift and score only the safe interior. Cropping after shifting prevents wrapped pixels from influencing the metric, while using the same region for every candidate keeps scores comparable.

03

Multi-Scale
Image Pyramid

Large TIFF plates can require displacements far beyond ±15 pixels, making a full-resolution exhaustive search expensive. Downsampling makes a large displacement small enough to recover with the same local search window.

I average each non-overlapping 2×2 block into one pixel. This is a simple box low-pass filter followed by a factor-of-two reduction—not a Gaussian pyramid. Matching pyramids are built for the reference and moving images until the largest dimension is at most 500 pixels.

Alignment begins at the coarsest level. At each finer level, I multiply the previous displacement by two and search a ±15-pixel neighborhood around that estimate. The final shift is applied to the original full-resolution channel.

Harvesters · naive stacking vs. pyramid L2

I later reran four residual failure cases with normalized cross-correlation while keeping the same pyramid and green reference. NCC subtracts each crop’s mean, normalizes both crops by their vector norms, and selects the largest correlation. This reduces sensitivity to simple cross-channel brightness differences without changing the translation model.

Kid still showed separation, so I tried a Sobel filter that I had just learned about in class. I am still learning how to use it well, but my current understanding is that Sobel estimates horizontal and vertical intensity changes and combines them into an edge-magnitude image. I aligned those edge maps with the same L2 pyramid, then applied the resulting shifts to the original channels—not to the edge images.

05

Emir of Bukhara:
A Reference-Channel Failure

Same metric.
Better reference.

With the normal pipeline, green aligns to blue reliably but red does not. Emir’s red- and blue-filtered exposures differ unusually strongly in raw intensity appearance, so direct red-to-blue L2 matching selects a visibly poor displacement. I kept L2 and the pyramid unchanged, fixed green instead, and aligned both blue and red to it. Green worked as a better common reference for this image; that is an empirical heuristic, not a general wavelength rule.

01

Diagnose the pair

Green and blue already agreed. The major error came from matching red directly to blue, whose corresponding regions did not look similar enough to raw-pixel L2.

02

Alternatives considered

I considered NCC, which mean-centers and normalizes image vectors, and Sobel gradients, whose derivative kernels emphasize edges. I later implemented NCC for four residual cases and then tried Sobel on Kid after NCC remained imperfect. Sobel had just been covered in class, and I am still learning the method.

03

Choose the simpler fix

Green gave L2 a more compatible comparison for both other channels, so changing only Emir’s reference solved the practical failure. I use the same fallback only on the few other plates where the blue-reference result is visibly worse.

07

Implementation Notes
& What I Learned

Images are arrays

Converting the plate to floating point made channel slicing, subtraction, squaring, and stacking direct NumPy operations.

Borders can dominate

np.roll is convenient, but its wraparound must be excluded from every score. Shift first, crop second, score third.

Coarse-to-fine scales

Box averaging shrinks the search problem enough to estimate large full-resolution shifts with the same small local window.

Reference choice matters

L2 compares intensities, not semantic structure. Emir showed that changing the comparison pair can matter as much as changing a metric.

08

Results &
Conclusion

The single-scale method aligns all three small JPEGs cleanly, and the same raw-pixel L2 objective becomes practical on high-resolution plates through the image pyramid. Most TIFFs converge to visually coherent reconstructions, and the Emir failure is resolved by changing only its reference channel.

The fixed pipeline is not perfect. Green-reference alignment resolves Church and Ordezh cleanly. NCC returned the same shifts as L2 for Ilemselga, Self-Portrait, and Three Generations. Sobel edge alignment gives Kid G→B (45, −13) and R→B (100, −21), but some separation remains. These experiments suggest that a single global translation cannot explain every residual difference; a more flexible motion model would be the next experiment.
